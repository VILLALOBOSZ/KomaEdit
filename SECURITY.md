# Security Policy

## Supported versions

Security fixes are prepared against `staging` and included in the next published prerelease. Stable fixes reach `main` only through an explicitly authorized release.

## Reporting a vulnerability

Do not publish exploitable details in a public issue. Use the repository's private GitHub Security Advisory form and include:

- affected KomaEdit, Minecraft, Fabric and WorldEdit versions;
- whether the problem occurs on an integrated or dedicated server;
- the minimum commands or project data required to reproduce it;
- crash reports or logs with tokens, addresses and personal information removed;
- the expected security impact, especially permission bypass, world corruption or unbounded resource use.

The maintainers will acknowledge a complete report, reproduce it on a private branch and coordinate disclosure after a fixed build is available.
